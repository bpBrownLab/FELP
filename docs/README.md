# FELP documentation

Start with the [repository README](../README.md) for installation, the workflow
figure and a score–summarize–plot example. The [theory guide](theory.md) derives
the estimator; [usage](usage.md) explains the inputs and output files.

| Guide | Contents |
|---|---|
| [Theory](theory.md) | Restricted partition functions, finite-sample reweighting and scoring assumptions |
| [Methods overview](methods.md) | A shorter account of the processing steps and diagnostics |
| [Usage](usage.md) | State definitions, CVs, restraints, subsampling and saved scores |
| [Manuscript protocol](manuscript_protocol.md) | Processing preset and system-specific scoring settings |
| [Neighbor pooling](neighbor_pool_reweighting.md) | Blend equations, stencil figures and L-curve selection |
| [Diagnostics](overlap_diagnostics.md) | Interpretation of k, ESS, U and H |
| [Harmonic exposure](harmonic_exposure.md) | Dirichlet construction, TV identity and a worked example |
| [Plotting](plotting.md) | Landscape figures, projection weights, units and display controls |
| [Benchmark reproduction](reproduce_matrix.md) | The 67-system, six-treatment sensitivity matrix |

For code changes, use the [source map](../felp/README.md),
[test guide](../tests/README.md) and [release instructions](../release/README.md).
Runnable templates and small input examples are in [examples](../examples/README.md).
